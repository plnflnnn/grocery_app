# Grocery App – Mobile Shopping Application

A cross-platform **mobile grocery shopping app** built with **React Native and Expo**.  
The app focuses on real-world mobile functionality such as product browsing, cart management, local storage, and payments.

This project was developed as a **full-featured mobile application**, with emphasis on **architecture, state management, forms and validation**.

---

## 📱 Overview

The Grocery App allows users to:

- Browse grocery products
- Add items to a cart
- Manage quantities
- Complete checkout with Stripe
- Persist data locally
- Work smoothly across iOS and Android

---

## 🛠 Tech Stack

### Core

- React Native
- Expo
- JavaScript
- SQLite (local database)
- Postgres

### Navigation

- React Navigation
  - Native Stack
  - Bottom Tabs

### UI & UX

- React Native Paper
- Vector Icons
- Responsive layouts

### Forms & Validation

- Formik
- Yup

### Payments

- Stripe (React Native SDK)

### Device & System

- Expo Secure Store
- Expo Image Picker
- Expo File System
- Expo Notifications
- Network status handling (`NetInfo`)

---

## ✨ Features

- 🛒 Product listing and cart functionality
- ➕ Add / remove items from cart
- 🔢 Quantity management
- 💳 Stripe payment integration
- 💾 Local data persistence with SQLite
- 📶 Network connectivity detection
- 🔐 Secure storage for sensitive data
- 📸 Image selection from device
- 📱 Cross-platform (iOS & Android)

---

## 🎯 Project Goals

This project was created to:

- Gain hands-on experience with **React Native + Expo**
- Work with **real mobile APIs and native features**
- Implement **payments in a mobile environment**
- Practice **form handling and validation**
- Build scalable app structure using contexts and hooks
